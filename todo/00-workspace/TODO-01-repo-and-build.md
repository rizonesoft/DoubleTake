# TODO-01 -- Repository and build

> **Goal:** One solution builds an empty engine library and its tests with one command, CI runs the same command, the photo fixtures and brand files are generated by scripts, and the repository carries the documents a public GPL project needs.

> **Current state:** Measured 2026-11-16. The repository holds the Conclave kits (`scripts/`, `.conclave/`, `todo/`), `design/` (SPEC, tokens, eight Darkroom mockups, two icon SVGs), `docs/plans/2026-11-16-doubletake-foundation.md`, `README.md`, `LICENSE` and `scripts/start-run.ps1`. `scripts/build-brand.py` already draws the app icon from the tokens into `resources/brand/` (`doubletake.ico` with eight sizes and `icon-<size>.png`), which the desktop campaign shortcuts use; it has no `--check`, no test, and draws nothing else yet. There is no solution, no `src/`, no `tests/` and no CI workflow. The build machine has Visual Studio 2026 (toolset `v145`), Windows SDK `10.0.26100.0`, the vcpkg bundled with Visual Studio, NuGet, CMake, Ninja, clangd 22, sccache, Python 3.14 with Pillow and fontTools, and Inno Setup 7 in `C:\Program Files\Inno Setup 7`.

- [ ] Add `tests/fixtures/make_fixtures.py` (Pillow) drawing at least 12 scenes at 2400 x 1800 from a fixed seed: skies, hills, shapes and noise textures that differ clearly between scenes (foundation plan section 8). - [ ] For each scene write the variants: original JPEG at quality 95, a 1200 x 900 resize, recompressions at quality 60 and 85, a PNG, a copy rotated in pixels and corrected through the EXIF orientation tag, a WebP, an AVIF, a light edit (brightness +6%), a 10% crop, and a byte-identical copy under another name.
